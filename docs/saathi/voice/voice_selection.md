# Voice selection

Default: **Sarvam via Bolna** (included in the ~$0.06/min flat rate).

- STT: `saaras:v4`
- TTS: `bulbul:v4-flash`
- Language code: `hi` (not `hi-IN`)
- `synth.provider_config.language` set
- `call_summary_enabled: true`

Deepgram / Cartesia: only if sponsor credits are confirmed **and** they appear on the wallet preferred-models list. Priyansh confirms amounts.

Persona: slow, warm, adult female. Prefer a Hindi-first voice that does not sound like a call centre.

Trial: omit `from_phone_number`; dial **Verified Numbers** only.
