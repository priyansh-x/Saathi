# Saathi — Latent Spaces film

HyperFrames composition for the product film: real family-desk screens in a phone frame, 1920×1080, 21.28s.

## Preview

```bash
cd composition
npx hyperframes@0.8.185 preview
```

## Check

```bash
cd composition
npx hyperframes@0.8.185 lint
npx hyperframes@0.8.185 check
```

Render only after you have watched the Studio preview and said to encode.

App stills live in `composition/assets/app/` (viewport captures of the family desk, 780×1688). Recapture if the desk UI changes.
